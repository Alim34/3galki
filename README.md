# Три галочки

Простой вечерний трекер: настроение дня + три привычки (✍️ писал, 🏋️ двигался, 📖 развивался).
Плохой день не считается провалом — цель видеть реальную жизнь, а не рисовать фальшивую картинку идеальной продуктивности.

## Структура проекта

- `www/` — веб-приложение (HTML/CSS/JS), это и есть весь интерфейс
- `capacitor.config.json` — настройки Android-обёртки (appId, название, цвет фона)
- `package.json` — зависимости Capacitor
- `.github/workflows/build-apk.yml` — сборка APK на GitHub Actions
- Папка `android/` не хранится в репозитории — она создаётся автоматически при каждой сборке (см. `.gitignore`)

## Как получить APK

1. Запушить изменения в ветку `main`.
2. Открыть вкладку **Actions** в репозитории — сборка `Build APK` запустится сама.
3. Дождаться зелёной галочки (первая сборка занимает ~5 минут).
4. Открыть завершённый запуск → внизу страницы раздел **Artifacts** → скачать `tri-galochki-apk`.
5. Внутри — файл `app-debug.apk`. Это debug-сборка: подходит для установки на свой телефон, но не для публикации в Google Play.

## Локальная разработка

Открыть `www/index.html` прямо в браузере — приложение работает без сборки и без сервера, все данные хранятся в `localStorage`.

## Куда развивать

- Сменить `appId` в `capacitor.config.json` перед реальной публикацией
- Добавить иконку приложения (`npx @capacitor/assets generate`)
- Экспорт/бэкап данных (сейчас данные живут только в localStorage телефона)
- Release-сборка с подписью — для публикации в Google Play
